📦 Task Description

You'll be rebuilding the Oman Gold Price Dashboard shown below, entirely from scratch, using it only as a visual and functional reference. It's an Angular single-page application styled with Tailwind CSS that displays gold prices in Oman, lets users calculate the value of a given weight of gold, and shows a 30-day price history in both chart and table form. The interface is written in Arabic and laid out right-to-left (RTL), so keep that in mind while you rebuild it.

Framework

Angular

Styling

Tailwind CSS

Language / Direction

Arabic (RTL)

✅ Requirements

Your rebuilt app must include the following functionality:

  • ✔ Display today's gold price for each karat: 18K, 21K, 22K, and 24K
  • ✔ A gold calculator: pick a karat and enter a weight in grams, then calculate the estimated total value
  • ✔ A 30-day price trend chart, switchable between karats, with current/highest/lowest summary stats
  • ✔ A price history table listing the last 30 days for all four karats
  • ✔ Navigation links that scroll to each section of the page
  • ✔ All data can be static/sample data — no real API or backend is required

🧩 UI Requirements

The page should follow this basic layout, top to bottom:

1. Header / Navigation

  • Sticky header with logo image and site name ("الذهب العُماني" / "Omani Gold")
  • Navigation links to the prices, calculator, and 30-day trend sections
  • A small badge label on the side (e.g. "Demo data")

2. Hero Banner

  • Large gradient banner with a breadcrumb line above it
  • Heading, short description paragraph, and a small pill/badge
  • A bottom info bar inside the banner showing "last updated" and market info

3. Today's Gold Prices

  • Section title and subtitle
  • A responsive grid of price cards, one per karat
  • Each card shows the karat label, the price, and the currency/unit
  • Build one reusable "price card" component and reuse it for every karat

4. Gold Calculator

  • A karat dropdown (select) and a weight-in-grams number input
  • A "Calculate" button
  • After clicking, show the estimated total value in a highlighted result card
  • Before calculating, show a placeholder/empty state instead

5. 30-Day Price Trend

  • Buttons to switch between karats (18K / 21K / 22K / 24K)
  • Three summary cards: current price, highest price, and lowest price over 30 days
  • A simple line chart (an SVG polyline is enough) plotting the last 30 days of prices
  • A small stats row comparing current price, previous price, and the change between them

6. Price History Table

  • A table listing 30 days of history with columns: date, 18K, 21K, 22K, 24K
  • Striped/alternating row colors and a horizontal scroll on small screens

7. Footer

  • Site name/title
  • Copyright line

🛠️ Technical Requirements

  • ✔ Build the app with Angular, styled with Tailwind CSS
  • ✔ Follow a clean, organized project/folder structure
  • ✔ Split the UI into reusable components (header, price card, calculator, chart, table, footer)
  • ✔ Use clear, meaningful names for components, variables, and functions
  • ✔ Avoid duplicating the same markup or logic — extract it into a shared component instead
  • ✔ Keep styling organized and consistent using Tailwind utility classes
  • ✔ Make the app responsive on desktop, tablet, and mobile
  • ✔ Store sample data (prices and history) in a simple data file or service
  • ✔ Make sure the project builds and runs without errors
